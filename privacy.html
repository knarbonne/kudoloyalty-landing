ปรับปรุงล่าสุด [วันที่มีผลบังคับใช้] · ใช้กับ kudoloyalty.io ระบบหลังบ้านสำหรับร้านค้า และแอปสำหรับสมาชิกของ Kudo

Kudo คือแพลตฟอร์มสะสมแต้มที่ทำงานอยู่ภายใน LINE นโยบายฉบับนี้อธิบายว่าเราเก็บข้อมูลส่วนบุคคลอะไรบ้าง เก็บไปทำไม แบ่งปันให้ใคร และคุณมีสิทธิอะไรเหนือข้อมูลนั้น เอกสารนี้ครอบคลุมคนสองกลุ่มที่ต่างกัน และความต่างนี้สำคัญตลอดทั้งฉบับ

  • ร้านค้า, ธุรกิจที่สมัครใช้ Kudo เพื่อทำโปรแกรมสะสมแต้ม
  • สมาชิก, ลูกค้าของร้านค้าเหล่านั้นที่เข้าร่วมโปรแกรมผ่าน LINE

1. ใครรับผิดชอบข้อมูลของคุณ

Kudo ดำเนินการโดย [ชื่อนิติบุคคล] จดทะเบียนในประเทศไทย เลขทะเบียน [เลขทะเบียนนิติบุคคล] ที่อยู่ [ที่อยู่จดทะเบียน]

ภายใต้พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ("PDPA") ความรับผิดชอบแบ่งตามว่าเป็นข้อมูลของใคร

  • ข้อมูลบัญชีของร้านค้า, Kudo เป็นผู้ควบคุมข้อมูลส่วนบุคคล
  • ข้อมูลของสมาชิก, ร้านค้าที่ทำโปรแกรมเป็นผู้ควบคุมข้อมูลส่วนบุคคล และ Kudo เป็นผู้ประมวลผลข้อมูลส่วนบุคคล เราดำเนินการกับข้อมูลสมาชิกตามคำสั่งของร้านค้านั้น หากคุณเป็นสมาชิกและต้องการให้ลบข้อมูล ร้านค้าเป็นผู้ตัดสินใจ แต่คุณติดต่อเรามาได้และเราจะส่งคำขอต่อให้

2. เราเก็บข้อมูลอะไรบ้าง

จากร้านค้า

  • ชื่อ อีเมล และข้อมูลธุรกิจที่คุณกรอกตอนตั้งค่า
  • รหัสบัญชี LINE Official Account และข้อมูลรับรองที่จำเป็นสำหรับการส่งข้อความในนามของคุณ
  • บันทึกการชำระเงินสำหรับแพ็กเกจแบบเสียค่าบริการ
  • ข้อความติดต่อฝ่ายสนับสนุน

จากสมาชิก

  • LINE user ID ชื่อที่แสดง และรูปโปรไฟล์ ซึ่งได้รับจาก LINE เมื่อคุณเข้าร่วมโปรแกรม
  • วันเกิด เฉพาะเมื่อ คุณให้ไว้ และใช้เพื่อให้ร้านค้าส่งของรางวัลวันเกิดเท่านั้น
  • ยอดแต้มหรือดวงตราสะสม และประวัติการได้รับและการแลก
  • ของรางวัลที่คุณแลกและเวลาที่แลก
  • กิจกรรมที่ใช้จัดกลุ่มคุณเป็น สมาชิกใหม่ ใช้งานอยู่ เสี่ยงหาย หรือ หายไป

เราไม่ได้รับรหัสผ่าน LINE ของคุณ ประวัติแชทของคุณกับผู้อื่น เบอร์โทรศัพท์ หรือรายชื่อเพื่อนของคุณ

ที่เก็บโดยอัตโนมัติ

  • หมายเลข IP ชนิดเบราว์เซอร์และอุปกรณ์ และหน้าที่เข้าชม
  • คุกกี้และการจัดเก็บลักษณะเดียวกันเท่าที่จำเป็นต่อการคงสถานะเข้าสู่ระบบและจดจำภาษาที่เลือก

3. เราใช้ข้อมูลเพื่ออะไร และใช้ฐานทางกฎหมายใด

วัตถุประสงค์ฐานทางกฎหมายตาม PDPA
ดำเนินโปรแกรมสะสมแต้ม, บันทึกแต้ม ออกของรางวัล ตรวจสอบการแลกการปฏิบัติตามสัญญา
ส่งข้อความของโปรแกรมผ่าน LINE ในนามของร้านค้าความยินยอม ที่ให้ไว้ตอนเข้าร่วมโปรแกรม
ของรางวัลวันเกิดและรางวัลตามเงื่อนไขพิเศษความยินยอม
การเรียกเก็บเงินและบัญชีสำหรับร้านค้าสัญญา และหน้าที่ตามกฎหมาย
ความปลอดภัย การป้องกันการฉ้อโกง และการแก้ไขข้อผิดพลาดประโยชน์โดยชอบด้วยกฎหมาย
สถิติภาพรวมที่ระบุตัวบุคคลไม่ได้ประโยชน์โดยชอบด้วยกฎหมาย

เราไม่ขายข้อมูลส่วนบุคคล และไม่ใช้ข้อมูลสมาชิกเพื่อโฆษณาให้กับผู้ใดนอกจากร้านค้าที่คุณเข้าร่วมโปรแกรมด้วย

4. LINE เกี่ยวข้องอย่างไร

  • เมื่อคุณเข้าร่วมโปรแกรม คุณอนุญาตให้ LINE แบ่งปัน user ID ชื่อที่แสดง และรูปโปรไฟล์ของคุณให้ร้านค้าผ่าน Kudo
  • ข้อความที่ร้านค้าส่งถึงคุณถูกส่งผ่าน LINE Messaging API และอยู่ภายใต้ข้อกำหนดและนโยบายความเป็นส่วนตัวของ LINE เอง
  • คุณบล็อกหรือเลิกติดตามบัญชี LINE ของร้านค้าได้ทุกเมื่อเพื่อหยุดรับข้อความ การทำเช่นนั้นไม่ได้ลบแต้มของคุณ หากต้องการลบ กรุณาติดต่อร้านค้า

เราอาจเปิดเผยข้อมูลเมื่อกฎหมายกำหนด หรือเพื่อก่อตั้งสิทธิเรียกร้องหรือต่อสู้คดี

6. ข้อมูลของคุณถูกเก็บไว้ที่ใด

ผู้ให้บริการโครงสร้างพื้นฐานของเราใช้ศูนย์ข้อมูลนอกประเทศไทย ปัจจุบันอยู่ที่ [ภูมิภาค เช่น asia-southeast1 สิงคโปร์] กรณีที่ข้อมูลส่วนบุคคลถูกส่งออกนอกราชอาณาจักร เราอาศัยมาตรการคุ้มครองที่กำหนดไว้ตามมาตรา 28 และ 29 แห่ง PDPA รวมถึงข้อผูกพันด้านการคุ้มครองข้อมูลตามสัญญากับผู้ให้บริการ

7. เราเก็บข้อมูลไว้นานเท่าใด

  • ข้อมูลสมาชิก, ตลอดระยะเวลาที่โปรแกรมของร้านค้ายังใช้งานอยู่ และอีก [N] วันหลังจากร้านค้าปิดบัญชีหรือลบสมาชิก จากนั้นจะถูกลบอย่างถาวร
  • ข้อมูลบัญชีร้านค้า, ตลอดระยะเวลาที่บัญชียังเปิดอยู่ และอีก [N] วันหลังปิดบัญชี
  • บันทึกการชำระเงิน, ตามที่กฎหมายภาษีและบัญชีของไทยกำหนด ปัจจุบันคือ 5 ปี
  • บันทึกระบบ, [N] วัน

8. สิทธิของคุณ

ภายใต้ PDPA คุณสามารถขอให้เรา

  • ส่งสำเนาข้อมูลส่วนบุคคลที่เรามีเกี่ยวกับคุณ
  • แก้ไขข้อมูลที่ไม่ถูกต้องหรือไม่สมบูรณ์
  • ลบข้อมูล หรือจำกัดการใช้ข้อมูล
  • โอนข้อมูลไปยังผู้ให้บริการรายอื่นในรูปแบบที่อ่านได้ด้วยเครื่อง
  • หยุดประมวลผลข้อมูล ในกรณีที่เราอาศัยฐานประโยชน์โดยชอบด้วยกฎหมาย
  • ถอนความยินยอมที่เคยให้ไว้ ซึ่งไม่กระทบการประมวลผลที่ทำไปแล้ว
